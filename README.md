# ⚡ EV Market Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing the Electric Vehicle (EV) market using data visualization and exploratory analysis. The dashboard presents key information about the EV market in an interactive and easy-to-understand format.

## 🎯 Project Objectives
- Analyze the available electric vehicle market dataset.
- Present important metrics and market trends visually.
- Make the data easier to understand through dashboard visualizations.
- Support data-driven exploration of the EV market.

## 🛠️ Tools & Technologies
- **Microsoft Excel** — Dashboard development and data analysis
- **CSV Dataset** — Data source
- **Git & GitHub** — Version control and project portfolio
